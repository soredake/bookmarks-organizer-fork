When enabled, link checks are sent through this FlareSolverr server. Keep the server private.
When enabled with FlareSolverr, domains that return 403 with Cloudflare markers are saved and distributed throughout the check.
When enabled, an invalid JSON response marks the domain as direct-only for the current check and retries the URL directly.
Try to avoid checking links from the same domain consecutively.
When enabled, checks visit bookmarks in inactive tabs so Firefox can cache their favicons. This may add entries to browsing history.
